# Новостной сайт

Учебная система редакции: администратор, главный редактор, редактор отдела, автор.
Бэкенд — FastAPI + SQLite, фронтенд — Vite + TypeScript без фреймворков.

## Запуск

Бэкенд (порт 8000):

```
cd backend
pip install -r requirements.txt
python -m uvicorn main:app --reload
```

Фронтенд (порт 5173):

```
cd frontend
npm install
npm run dev
```

База `backend/news.db` создаётся сама при первом запуске: четыре отдела
(Политика, Экономика, Спорт, Культура) и администратор **admin / admin**.
Чтобы начать с нуля — удалить файл `news.db`.

## Роли

Роль — это класс в [backend/models.py](backend/models.py); набор строк в `can` и есть права,
которые проверяет API.

| Класс | Роль | Может |
|---|---|---|
| `Admin` | Администратор | `users` — список сотрудников: должности, отделы, удаление |
| `ChiefEditor` | Главный редактор | `topics` — темы выпуска по отделам; `review` — видит все публикации и их статусы |
| `DepartmentEditor` | Редактор отдела | `assign` — публикации по авторам; `edit` — правка; `approve` — разрешение на выкладку |
| `Author` | Автор | `write` — подготовка публикации и исправление замечаний |

Редактор и автор работают только со своим отделом — это проверяется на сервере.

## Жизненный цикл публикации

```
редактор поручает автору   -> assigned  (назначена автору)
автор сдаёт                -> submitted (на проверке у редактора)
редактор вернул с замечанием -> rework   (на доработке, note = замечание)
автор сдаёт заново         -> submitted
редактор разрешил выкладку -> approved  (видна в ленте /api/news)
```

## Регистрация

Любой может зарегистрироваться и выбрать должность; для редактора отдела и автора
обязателен отдел. Дальше должность и отдел меняет администратор.

## Структура

```
backend/
  models.py   классы ролей и права
  db.py       схема SQLite, стартовые данные, три помощника вместо ORM
  main.py     все эндпоинты API
frontend/src/
  api.ts      fetch + токен в localStorage
  app.ts      шапка, выбор экрана по роли, перерисовка
  ui.ts       экранирование, формы, обработчики, подписи статусов
  views/      news, auth, admin, chief, editor, author
```

Авторизация учебная: пароль — sha256 без соли, токен живёт в памяти процесса,
поэтому после перезапуска бэкенда нужно войти заново.
